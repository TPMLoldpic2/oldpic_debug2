臺北跨時空：iPhone 底部導覽列修正版（v8）
========================================

這個壓縮檔是「替換用檔案」，並非完整網站素材包。

修正內容：
1. 加入 viewport-fit=cover，讓畫面可正確處理 iPhone 全螢幕 PWA 的安全區域。
2. 底部選單高度加入 safe-area-inset-bottom，延伸背景到手機最下緣，避免卡片圖片露在選單下方。
3. 底部選單補上不透明底色，即使背景圖片有透明區域也不會透出下面的卡片。
4. 主頁面底部保留與安全區域相符的捲動空間，最後一張卡片仍可完整捲動查看。
5. 最上方預留 iPhone 狀態列的安全空間（原本系統黑底保留）；掃描提示文字也避開上方安全區域。
6. Service Worker 快取版本更新，協助 iPhone 重新取得新版網頁。

部署：
1. 解壓縮，將「index.html」及「sw.js」這兩個檔案上傳到原本 GitHub Pages 的網站根目錄，覆蓋同名舊檔。
2. 保留原站所有其他檔案與資料夾，例如 manifest.webmanifest、data.txt、connect.txt、targets.mind、background/、images/、icons/、videos/，不要刪掉。
3. GitHub Pages 更新後，在 iPhone 完全關閉並重新打開網站（或主畫面的 PWA），再往下捲動測試。若仍看到舊版，可嘗試重新整理或重新將網站加入主畫面。

測試說明：
已進行 JavaScript 語法檢查、HTML 結構檢查，並用 390×844 手機模擬視窗確認導覽列貼齊底部；亦以模擬 59px 頂部安全區及 34px 底部安全區的版面測試確認結果。
尚無法在使用者的實體 iPhone 上驗證，部署後建議用原手機再次確認。
